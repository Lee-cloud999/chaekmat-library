# 📚 책맛서재

책을 맛보듯 읽고, 마음에 남은 문장을 모아 두는 나만의 작은 서재.

**바로 쓰기:** https://lee-cloud999.github.io/chaekmat-library/

## 지금 할 수 있는 것 (1단계)
- 🔍 카카오 책 검색으로 책 찾아 담기 (검색에 없는 책은 직접 담기)
- 📚 가상 책장에 책등으로 꽂히는 나의 서재
- 🗂️ 독서 보드: 읽고 싶은 책 / 읽는 중 / 다 읽음 — 카드를 끌어서 옮기기
- ✍️ 책마다 마음에 남은 문장 기록, 문장 서랍에서 한눈에 보기
- 💾 백업 파일 받기·불러오기

## 카카오 API 키
책 검색에는 카카오 REST API 키가 필요해요. 키는 코드에 들어 있지 않고,
앱의 ⚙️ 설정에 입력하면 그 기기의 브라우저에만 저장돼요.
